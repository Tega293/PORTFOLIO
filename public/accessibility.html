Accessibility

Updated 1 November 2026

I want the portfolio to be usable with different devices and input methods. The site is responsive and includes semantic page landmarks, labelled navigation controls, visible keyboard focus, text labels for interactive diagrams, and reduced-motion handling.

Using the interactive AI Lab

  • Use Tab and Enter or Space to operate buttons, attention cells, and network input nodes.
  • Embedding points can be selected with Tab and moved with the arrow keys; pointer users can drag them.
  • Range controls support standard keyboard operation.
  • Sound is off by default and can be enabled or muted with the labelled control.

External previews

Embedded project previews are optional and load only after you choose. They are read-only previews and cannot receive pointer or keyboard interaction; use the adjacent “Open” link to visit the project directly, or choose “Unload preview” to remove the embed. A third-party project may have accessibility features or barriers outside my control.

Feedback

If you find a barrier or need information in another format, email oyibochaoghenetega5@gmail.com and describe the page and task. I will review the report and work on a practical improvement.

This statement describes the current design intent and known controls; it is not a claim of formal accessibility certification.
